# FitCoach Context

## Glossary

### Plan Type
A long-lived formal plan selected by the user for the current period. A plan type changes how FitCoach generates daily prescriptions, nutrition guidance, and review logic.

### Cut Plan
A plan type where the user remains in active formal strength training while the system shifts the objective toward fat loss rather than lean gain.

### Stop-Training Plan
A plan type where the user pauses formal training for a defined period. FitCoach should not generate normal A/B/C strength-training prescriptions during this period.

Stop-training plans must be created with an explicit start date and end date.
Stop-training plans must also capture a pause reason or goal type, because nutrition and daily guidance depend on why the user is pausing training.
The first version should use three fixed stop-training types:
- Recovery
- Life/Admin disruption
- Weight-control without formal training

When a stop-training plan ends, FitCoach should choose the default return path based on pause length:
- For pauses within 7 days, default toward resuming the prior formal plan.
- For pauses longer than 7-14 days, default toward generating a new formal plan.

### Formal Strength Training
The normal A/B/C strength-training prescription flow generated by FitCoach, including workout templates, daily training prescriptions, and training-day reporting.

### Temporary Training Pause
A short-lived interruption inside an existing plan, such as travel, illness, schedule disruption, or a brief recovery block. This is not a new formal plan type by default.
